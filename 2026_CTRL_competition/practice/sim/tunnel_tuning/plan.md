# 터널 라이다·회피 튜닝 계획 — 2026-10-12

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 승인된 1·2·3 순서로 직접 실행한다.

**Goal:** 카메라 추가 없이 50 km/h 상한에서 불필요한 감속·양보 대기와 통과시간 편차를 줄인다.
**Architecture:** 기존 라이다 추적, YIELD, 단순 좌우 경로 선택을 유지한다. 측정 기록으로 기존 파라미터의 영향을 먼저 비교하며, 파라미터로 해결되지 않는 버그만 기존 코드의 최소 수정으로 처리한다.
**Tech Stack:** Python, ROS 2 Humble, NumPy, pytest, 기존 MORAI loop_runner와 rosbag 분석 도구.
**Spec:** ../../../../HANDOFF_터널_2026-10-12.md 및 사용자 승인(카메라 보류, 1·2·3 진행, 기존 파라미터 우선).

## Global Constraints

- 터널 상한 50 km/h, 라이다 설정 10 Hz 유지.
- 회전교차로·카메라 변경 금지. 전역 제어 파라미터는 다른 미션 영향 때문에 우선 변경하지 않는다.
- 수치를 추가하거나 예외 분기를 추측으로 붙이지 않는다. 기존 파라미터·상수도 측정 근거로만 조정한다.
- 시뮬 조작이 불명확하면 사용자에게 질문한다. 현재 배치를 보존해야 하는지는 질문 응답 후 판단한다.
- 공유 RViz·시뮬 창과 네트워크를 재시작하지 않는다. 분석의 정답 데이터는 practice 안에서만 쓴다.
- main 머지·push는 하지 않는다. 기존 tunnel-simple-planner 작업 트리를 사용한다.

## Review Focus

- 낮은 링 단면으로 보이는 실제 사람·동물의 주의 표시를 잃지 않는다.
- 추적 ID가 바뀌거나 관측이 없어졌다는 이유만으로 위험 대상에서 출발하지 않는다.
- 새 장애물·좁은 통로에서 기존 충돌 검사가 유지된다.
- 경로 전환·감속·정지 직후에도 제어 주기가 크게 끊기지 않는다.
- 정적 장애물 미션과 터널이 공유하는 회피 파라미터의 영향을 검증한다.
