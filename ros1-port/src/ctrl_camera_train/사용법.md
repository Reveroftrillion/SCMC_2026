# CTRL 팀 데이터 도구 사용 순서

이 안내는 수집·추출·학습을 구분한다. 과거 외부 PC에서 사용한 `2026Morai`/ROS2 명령은 현재 ROS1 실행 명령으로 재사용하지 않는다.

## 1. 수집 준비

[record.yaml](config/record.yaml)의 카메라/출력 설정과 실제 시뮬레이터를 확인한다. 전용 수집 launch의 ROS1 연결은 아직 확인이 필요하다. production 주행 실행은 [ROS1 안내](../../README.md)를 따른다.

## 2. 저장된 세션 추출

해당 패키지가 Python 경로에 있고 필요한 의존성이 설치된 환경에서, 이미 저장된 세션을 명시한다.

```bash
python3 -m ctrl_camera_train.ctrl_extract --session /path/to/session --out /path/to/ctrl-output
```

`/path/to/...`는 실제 팀 데이터 위치로 바꾼다. 이 명령은 기존 세션의 라벨 초안을 만드는 예시이며 새 수집이나 주행을 시작하는 명령이 아니다. 이 문서 작업에서 실행하지 않았다.

## 3. 검수와 학습 전 확인

세션 metadata와 원본, 라벨 초안/검수 자료, 중단 상태와 train/val 분할을 확인한다. 학습 전 설정 검사:

```bash
python3 -m ctrl_camera_train.ctrl_train --data /path/to/data.yaml --check-only
```

학습은 입력·제공 근거·리소스·평가 계획을 확정한 뒤 별도 실행한다. 모델을 자동으로 production 파일에 덮어쓰지 않는다. 자세한 기록 조건은 [개발 명세](개발명세서.md)에 있다.
