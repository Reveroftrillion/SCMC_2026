# CTRL 팀 데이터 도구 구성과 작업 흐름

이 안내는 현재 모듈의 담당 기능과 데이터 처리 순서를 정리한다. 이전 작업 일지와 측정 내역은 아래 보관 기록에서 확인한다.

| 모듈 | 책임 |
| --- | --- |
| `ctrl_recorder_node` | RGB/semantic 쌍과 metadata 수집 |
| `ctrl_collect_label` | 수집 세션과 추출 작업 조정 |
| `ctrl_extract` | semantic 기반 라벨 초안·검수 자료 생성 |
| `ctrl_stoplines`, `ctrl_stop_lines` | 경로/정지선 데이터 연결 |
| `ctrl_palette` | semantic 색 해석 |
| `ctrl_train` | 학습 설정 점검과 학습 호출 |
| `ctrl_evaluate` | 정지선/경로 기준 평가 |
| `ctrl_survey`, `ctrl_roboflow_io` | 보정·교환 형식 관련 보조 작업 |

`ctrl_stop_lines`는 [카메라 패키지](../ctrl_camera/README.md)에 있다. 수집 조건은 [record.yaml](config/record.yaml)을 확인한다. 이 파일의 수집용 센서와 실제 주행용 Camera-7 설정을 서로 대체하지 않는다.

작업은 원본 세션 → 라벨 초안 → 검수 → 학습/검증 분할 확정 → 모델 생성 → 평가 순서로 진행한다. 입력 원본을 보관하고 단계마다 입력 hash, 사용 설정과 출력 위치를 남긴다. 데이터 제공 경위와 라이브러리 작성 정보도 함께 유지한다.

실제 ROS1 수집 실행 경로와 데이터 근거는 [사용법](사용법.md), 모델/자산 확인은 [출처 안내](../../docs/SOURCES_AND_HISTORY.md)를 따른다.
