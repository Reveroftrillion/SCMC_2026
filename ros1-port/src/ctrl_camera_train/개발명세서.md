# CTRL 팀 데이터 수집·학습 작업 기준

수집 입력, 학습 자료와 평가 결과를 같은 조건으로 다시 확인할 수 있게 관리한다. 실행 환경과 시험 결과에는 해당 작업의 조건을 적고, 이전 환경의 성과를 현재 결과로 계산하지 않는다.

## 수집 전에 남길 항목

세션마다 장면, 날씨/시간, 카메라 위치·각도·해상도·FOV, RGB/semantic 동기, 경로 버전과 위치 유효성을 기록한다. 태그는 조건 이름이며 시뮬레이터 설정을 변경했다는 증거가 아니다.

수집 도구가 제어를 송신하는지와 노드 종료/저장 완료를 확인한다. 현재 보존된 수집 launch는 ROS2 형식이며 ROS1 전용 연결의 검증이 남아 있다. 실행되지 않은 수집을 성공으로 표시하지 않는다.

## 라벨 확인과 데이터 분할

자동 추출은 라벨 초안이다. 신호 박스·색·ROI·픽셀 경계와 누락을 검수한다. 위치 정보가 없거나 세션이 중단된 자료의 처리 여부를 명시한다. 같은 장면의 인접 프레임이 학습과 검증에 섞여 성능을 부풀리지 않도록 조건/정지선/세션 단위 분할 근거를 남긴다.

## 학습 실행과 결과 확인

데이터와 기반 가중치의 제공 근거, 사용 코드·설정, seed·분할·해상도·클래스와 export 결과를 기록한다. 검출 지표와 실제 신호 정지는 별도로 평가한다. 모델 파일의 존재만으로 자체 학습이나 주행 통과를 판정하지 않는다.

현재 모델의 원래 메타데이터는 [models/README](../ctrl_camera/models/README.md)에, 확인이 남은 자산은 [자산 목록](../../docs/independent_assets_2026-10-25.json)에 있다. 현재 코드 역할은 [개발 구조](개발구조.md)를 따른다.
