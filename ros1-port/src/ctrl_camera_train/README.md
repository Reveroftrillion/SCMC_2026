# CTRL 팀 신호 데이터·학습 도구 — ctrl_camera_train

RGB/semantic 수집, 라벨 초안 추출, 검수와 학습/평가를 지원하는 보조 패키지다. 현재 production 주행의 모델이 이 도구로 CTRL 팀에서 학습됐다는 뜻은 아니다.

- [사용법](사용법.md): 수집·검수·학습 전 점검 순서
- [개발 구조](개발구조.md): 모듈과 데이터 흐름
- [개발 명세](개발명세서.md): 데이터와 결과를 기록할 조건

`launch/ctrl_record.launch.py`는 현재 남아 있는 ROS2 형태의 수집 launch다. catkin의 설치 규칙은 XML `.launch`를 대상으로 하므로 이를 그대로 ROS1 수집 실행 명령으로 안내하지 않는다. 전용 수집 경로의 ROS1 연결은 별도 확인이 필요하다.

기존 수집 카메라 설정과 기본 로그 디렉터리에는 외부 참고 구현의 값이 남아 있다. 팀 데이터 경로를 명시적으로 지정하고, 실제 수집/학습을 수행한 경우에만 새 결과로 기록한다.
