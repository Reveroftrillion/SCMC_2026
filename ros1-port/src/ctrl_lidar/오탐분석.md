# CTRL 팀 LiDAR 오탐·누락 분석 절차

이 문서는 현재 분석 순서를 정리한다. 이전 작성자의 2026년 측정 일지와 성공/실패 숫자는 아래 보관 원문에 남겼다.

## 분석 순서

1. 실패 시각의 raw scan, 차량 pose, 센서 장착 TF와 시각을 고정한다.
2. 센서 좌표와 base/map 좌표, 단위·시간축의 일관성을 확인한다.
3. 지면 평면과 점의 상대 높이, 경사·강도·지원 영역을 본다.
4. 군집/외곽의 크기·분할·병합과 추적 속도를 확인한다.
5. 도로 포함/가시성/mission 만료가 관측을 어떻게 바꿨는지 확인한다.
6. 인지 출력이 planning의 기억·정지·우회 선택에 반영된 위치를 추적한다.

지면 오탐을 줄이는 변경과 실제 낮은 물체를 남기는 조건을 함께 검사한다. 보행자가 정지했다고 정적 장애물로 우회하거나, 부분 외곽 중심의 이동을 그대로 실제 속도로 판단하지 않는다.

## 결과 기록

입력 hash, 코드 버전, 실패 재현, 수정 전후 같은 입력 결과, 실제 물체 보존과 미검증 장면을 새 기록에 남긴다. 통과를 위해 기대값·ROI·threshold를 근거 없이 바꾸지 않는다. 과거 주행 성공을 새 배치나 새 구현의 검증으로 다시 사용하지 않는다.
