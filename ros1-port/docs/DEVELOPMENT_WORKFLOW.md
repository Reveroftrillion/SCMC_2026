# CTRL 팀 작업 계획과 인계

기준일은 2026-10-25다. CTRL 팀은 미션 요구사항을 바탕으로 기능을 설계하고, 확인한 단위부터 현재 주행 스택에 반영한다. 작업 모델은 Sol Medium을 기본으로 사용하며 해결되지 않은 문제에 한해 상향한다.

문서별 합성 장면과 step은 각각의 확인 범위를 나타낸다. 이를 합쳐 실제 주행 횟수로 세지 않는다. 현재 production launch에서 실행되는 것은 기존 ROS1 이식·수정 경로다.

## 이어서 진행할 작업

- 작업 목적: 구현한 비교 기록 연결을 Linux에서 확인하고 실제 입력 기록으로 계산 차이를 확인한다.
- 수정 범위: 차량 설정·실제 입력 기록 확보, Linux 빌드/메시지/시간축 확인, 결과 분석과 관련 오류 수정.
- 반영 절차: metadata·시간축·좌표·global station의 의미를 유지한다. 경로 revision이 달라지면 전역 검색 범위를 지정해 진행을 재획득하며, 이전에 채택한 조향각을 다음 계산에 전달한다.
- 확인 절차: 기존 제어 출력이 유지되는지 확인하고 새 계산의 오류·지연·경로 차이를 기록한다. 실제 기록 재생과 Linux catkin/ROS 메시지 연결도 확인한다. 제어 출력을 바꾸는 시험은 별도 승인을 받은 뒤 수행한다.
- 종료 조건: 일반/회피/local reference 및 전환 장면을 확인하고, 차량 파라미터·조향 응답·실제 추종 오차와 해결되지 않은 실패를 인계한다.

현재 확보한 것은 오프라인 계산 기반과 기본 비활성 비교 기록 연결이다. 1단계 완료 여부는 Linux 실행 연결과 주행 확인까지 마친 뒤 판단한다. Windows 결과를 Linux/ROS/MORAI의 통과 결과로 대신하지 않는다.
