# CTRL 팀 문서·코드 출처와 연도

## 현재 CTRL 문서

루트/ROS1/Docker 안내, 현재 개발 계획과 패키지 안내는 CTRL 팀이 이 저장소를 개발·운영하기 위한 현재 설명이다. 외부 문서의 팀 이름만 치환하지 않고 현재 코드 역할과 검증 상태를 기준으로 다시 작성했다.

현재 production 스택은 외부 참고 코드의 ROS1 이식·수정 경로를 포함한다. 새 조향/진행/변환/요청 관리 모듈은 오프라인 개발 중이며 현재 launch에 연결되지 않았다. 문서를 바꿨다고 실행 코드 전체가 독자 구현으로 교체된 것은 아니다.

## 외부 참고 코드

`2026_CTRL_competition/`과 `과거자료/2026foscar*`는 FOSCAR의 2026 참고 구현·기록으로 보존한다. 원래 작성자·URL·라이선스와 날짜를 유지한다. 이 자료를 2025년 코드나 CTRL 팀 전체 작성물로 표시하지 않는다.

## 작년 자료

`과거자료/sim_2025/`는 2025 자료로 보관된 simulator/ROS 코드다. 현재 시점인 2026년 문서에서 '작년 참고 코드'는 이 범위를 뜻한다. 폴더 이름만으로 세부 파일의 개별 작성 연도나 소유권까지 단정하지 않는다.

## 원문·검증 근거

문서 교체 전 본문은 `과거자료/ctrl-document-history-20261025/`에 원래 바이트로 저장한다. 과거 기술 문서/날짜별 검증과 JSON·SHA256 manifest는 원래 기록으로 유지한다. snapshot 안의 상대 링크·명령은 원래 파일 위치와 당시 환경을 기준으로 읽는다.

모델 메타데이터와 점군 fixture 설명은 과거 측정·외부 의존성의 근거라서 이름을 바꾸지 않는다. 자산 사용 근거와 자체 생성 여부의 열린 항목은 [자산 목록](independent_assets_2026-10-25.json)에 있다.

현재 문서의 목적은 사용법과 개발 상태를 정확하게 전달하는 것이다. 출처나 실험 사실을 숨기는 용도로 이름·연도를 고치지 않는다. [전체 목차](MARKDOWN_INDEX.md)에서 현재 안내와 보관 기록을 구분해 찾는다.
