# 경로 진행 구간 관리 명세 — 2026-10-25

## 목표와 범위

새 조향 계산에 전달하는 `TrackingReference`의 위치 검색 구간을 관리한다. [제어 명세](CONTROL_CONTRACT_2026-10-25.md)의 polyline 거리와 후륜축 기준을 따른다. 기존 ROS 노드나 원본 helper를 사용하지 않으며, 실제 제어 연결은 후속 작업이다.

영향 파일은 새 `ctrl_progress.py`, 관련 검사·검증 도구·문서와 `ctrl_lateral.py`의 공개 위치 투영 API 추가다. 기존 조향 계산 정책·합성 합격선·생산 launch를 변경하지 않는다.

## 상태와 입력

- `ProgressTracker`는 불변 polyline, 현재 투영 station, 지금까지의 최대 station, 마지막 채택 pose/시각, 완료 여부를 보관한다. 이 station은 전역 `global_s`나 lap 수가 아니다.
- 최초 `acquire()`와 경로 교체는 호출자가 검색 시작/끝 station을 직접 지정한다. 이전 경로 station을 새 경로에 암묵적으로 복사하지 않는다. 실패한 교체는 기존 상태를 보존한다.
- 정상 `update()`에는 pose, 현재 시각, 추종 요청 시각을 전달한다. 같은 path의 형상 변경도 새 `acquire()`가 필요하다. 추종 요청 시각을 pose 시각으로 임의 갱신하지 않는다.
- 검색 범위는 `[최대 station - backtrack, 이전 투영 station + max_speed * 경과시간 + forward_margin]`을 경로 범위로 제한한다. backtrack은 작은 위치 흔들림의 여유이며 후진 주행 허용이 아니다.
- `max_speed`, backtrack, forward margin, 입력 나이, 경과시간 한계, 경로/방향 오차, 끝점 허용거리를 설정으로 받는다. 숨은 차량 기본값을 두지 않는다.

## 채택 조건과 실패 처리

1. 같은 frame, 유한한 값, 전진 속도 `0 <= speed <= max_speed`, 입력 시각의 나이/미래 허용 범위를 만족해야 한다.
2. 정상 갱신에서 현재 시각과 pose 시각은 마지막 채택값보다 커야 한다. 추종 요청 시각은 같아도 되지만 역행하면 안 된다.
3. 마지막 채택 이후 `max_gap`을 넘으면 명시적 재획득이 필요하다. 시계 역행도 자동 reset하지 않는다.
4. 실제 위치 이동거리도 `max_speed * 경과시간 + forward_margin` 이내여야 한다. 큰 위치 점프를 검색창 끝점에 억지 투영해 채택하지 않는다.
5. 검색 구간에서 위치 투영이 유일해야 하며 경로 거리와 방향 오차 한계를 만족해야 한다. 자기 교차의 서로 다른 station이 동률이면 거부한다.
6. 뒤쪽 검색 경계에 투영이 잘린 경우에는 실제 pose가 그 경계의 뒤에 있는지 접선 성분으로 검사해 거부한다. 작은 역방향 흔들림은 raw station에 반영하되 최대 station은 줄이지 않는다.
7. 모든 검사를 통과한 경우에만 상태를 한 번에 교체하고, 조향 모듈에 전달할 새 reference를 반환한다. 실패 결과의 reference는 `None`이며 이전 상태는 진단용으로만 보존된다.

경로 끝 완료는 남은 경로 길이와 실제 끝점 거리 모두 `end_tolerance` 이내일 때 채택한다. 완료 상태는 같은 경로에서 유지하며 자동으로 시작점으로 돌아가거나 다음 lap으로 넘어가지 않는다. `reset()`은 명시적으로 상태를 비운다. 진행 완료 자체는 정지 명령이 아니다.

위치 투영은 새 조향 모듈의 공개 `project_position()`을 공유한다. 이 API는 경로/frame/검색 범위와 기하만 검사하며 시각·속도·동역학 판단은 호출자의 책임이다.

## 구현 전 고정한 검증 항목

- 최초 획득, 연속 전진, 정지 중 작은 위치 흔들림, 최대 station의 단조성.
- 시작점과 종료점이 가까운 경로 및 자기 교차에서 지정한 구간 유지.
- 큰 위치 점프, 과도한 후퇴, 속도 한계, 검색 구간 모호성 거부.
- 중복/역행 pose 시각, 시계 역행, 추종 요청 역행·만료, 긴 관측 공백과 허용 경계.
- 실패 후 상태 불변, 잘못된 경로 교체의 원자성, 새 경로 거리 원점, 명시적 reset/재획득.
- 끝점 근접만으로 완료하지 않음, 완료 후 시작점으로 자동 복귀하지 않음.
- 반환 reference를 새 조향 모듈에 전달해 검색 구간이 실제로 사용되는지 확인.
- 기존 조향 115개와 합성 10개 장면의 기존 합격선 유지. 진행 관리자+조향 결합 검사에서도 같은 물리 장면/오차 기준을 사용.

합성 진행 설정은 `tools/progress_cases.json`에 고정한다. 실제 차량 설정으로 간주하지 않는다. ROS/catkin, 실제 기록 재생과 MORAI 주행은 이번 범위에 포함하지 않는다.
