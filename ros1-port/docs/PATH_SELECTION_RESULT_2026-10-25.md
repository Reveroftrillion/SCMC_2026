# 경로 요청 선택·유지·해제·만료 구현 결과 — 2026-10-25

[수명 관리 명세](PATH_SELECTION_CONTRACT_2026-10-25.md)에 따라 `ctrl_control/ctrl_path_selection.py`를 구현했다. 표준 라이브러리와 앞선 새 경로 변환 모듈만 사용한다. 실제 ROS 구독이나 제어 송신에는 연결하지 않았다.

## 구현한 처리

- 요청의 frame/시각/속도·정지 메타데이터와 경로 필드를 함께 검증·채택한다. ROS1 형태의 메시지를 ROS import 없이 불변 요청으로 복사한다.
- 동일 reference ID의 좌표/전역 라벨 변경을 거부하고, 새로운 ID의 기록 수와 경로 크기/점 간격을 제한한다.
- reference 배열이 없는 heartbeat에서도 명시적 해제 전까지 활성 reference를 유지한다. chain은 명세에 따른 회피 우선순위를 가진다.
- entry 없는 offset에는 명시적인 transition anchor가 필요하다. 반복 요청은 같은 경로와 anchor를 재사용해 전환이 매번 다시 시작되지 않는다.
- 회피 완료 위치와 최종 zero offset을 확인한 뒤 기본 경로로 복귀한다. 완료 확인 없는 빈 요청은 기존 계획을 유지한다.
- 오래된/중복/과도하게 미래인 요청은 수명을 연장하지 않는다. 유효한 새 시각의 malformed 요청은 기존 경로를 진단용으로만 남기고 출력을 차단한다.
- 시계 역행은 명시적 reset을 요구한다. 실패나 만료 결과의 선택 상태는 `None`이다. 자동 fallback을 제어 출력으로 내보내지 않는다.

새 geometry revision을 받은 호출자는 전역 station 범위를 새 경로의 local 거리로 바꿔 진행 구간을 다시 획득해야 한다. 이전 조향각은 별도로 유지해 변화율 제한을 적용한다. 이번 연속 검사에서 이 연결 순서를 확인했다.

## 검증 결과

| 검사 | 결과 |
| --- | --- |
| 신규 선택/수명 관리 검사 | 57 PASS |
| 기존 변환/진행/조향 검사 | 221 PASS |
| 합계 | 278 PASS, 실패·오류·skip 0 |
| 선택→변환→진행→조향 연속 검사 | 2개 장면·2,500 step 모두 PASS |

| 연속 장면 | 실제 mode 순서 | 최대 오차 | 마지막 2초 RMS | 마지막 오차 |
| --- | --- | ---: | ---: | ---: |
| 회피 완료 후 기본 경로 복귀 | offset → global | 0.40m | 0.05483m 이하 | 0.04470m 이하 |
| reference heartbeat 유지 후 해제 | reference → global | 0.40m | 0.02647m 이하 | 0.01762m 이하 |

heartbeat를 반복하면서도 각 장면의 활성 경로 객체는 회피/reference 1개와 기본 경로 1개로 유지됐다. 경로 교체 전후 조향각/변화율 한계와 명시적인 진행 재획득도 통과했다. 최종 위치 오차는 합성 허용치 0.35m 이내다.

초기 275개 통과 후 메시지 디코딩 순서의 경계 3개를 추가했다. 과거/미래의 손상 배열을 먼저 디코딩해 기존 출력을 차단하는 문제와, 신선한 디코딩 실패가 요청 순서 기록에 반영되지 않아 이전 packet으로 복구되는 문제를 3 FAIL로 재현했다. header 시각의 순서/나이를 먼저 확인하고 신선한 디코딩 실패의 시각을 기록하도록 수정했다. 기대 조건은 유지했으며 최종 278개와 연속 장면을 새 폴더에서 다시 검증했다.

이 결과는 조향 지연·미끄러짐·센서 잡음·도로/충돌 모델이 없는 합성 검사다. 오류 반환을 실제 제동/인계로 연결하는 상위 제어도 아직 없다. 실제 주행 안전성이나 대회 완주 성능을 증명하지 않는다.

## 재현

저장소 루트 PowerShell에서 실행한다.

```powershell
& .\ros1-port\.python310\python.exe -X utf8 -B .\ros1-port\tools\validate_path_selection.py
```

새 `verification/.work/independent-path-selection-*` 폴더에 단위 log/XML, mode/revision/전역 station/조향/오차 CSV, 코드/검사/명세 SHA256을 포함한 보고서를 남긴다. 출력 폴더가 이미 있으면 중단한다.

최종 결과 폴더: `verification/.work/independent-path-selection-20261025-032611Z-5456e0c4/`. 공유 요약: [JSON 결과](path_selection_result_2026-10-25.json). 초기 결과 폴더와 앞선 모든 검증/manifest를 보존했다.
