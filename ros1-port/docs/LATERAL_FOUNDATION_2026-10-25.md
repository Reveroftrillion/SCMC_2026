## 설계와 코드 범위

- 경로 점을 불변으로 복사하고 선분 투영/보간을 직접 구현했다. 검색 구간을 호출자가 지정하며 자기 교차의 동일 거리 후보를 모호성으로 보고한다.
- 좌표와 시각/경로 진행거리 계약을 먼저 명세하고, 목표점을 차량 좌표로 바꿔 Pure Pursuit의 기하식으로 조향을 계산한다. 공개 원문과 이번 선택 정책은 명세에 기록했다.
- 조향각과 명령 변화율 한계를 따로 적용한다. 물리적인 조향 액추에이터 응답을 보장하는 것은 아니다.
- 입력 오류·만료·방향/경로 오차·경로 끝에서는 유효하지 않은 결과와 사유를 낸다. 이 경우 조향값은 `None`이며, 상위 제어기가 정지/인계 정책을 담당해야 한다.
- 기존의 회피 곡선, 적분 보정, 속도 제어, 센서 수신, 차량 명령 송신을 새 모듈에 복사하지 않았다. 기존 주행 코드는 그대로 남아 있으며 혼합 개발 단계다.

## 재현

저장소 루트에서 Windows의 기존 Python으로 실행한다.

```powershell
& .\ros1-port\.python310\python.exe -X utf8 -B .\ros1-port\tools\validate_lateral.py
```

Python/pytest가 준비된 Linux에서는 다음을 사용한다. 이 명령 자체의 Linux 실행은 아직 확인하지 않았다.

```bash
python3 -B ros1-port/tools/validate_lateral.py
```

매번 `ros1-port/verification/.work/independent-lateral-*` 새 폴더에 `report.json`, `trace.csv`, `unit.log`, `unit.xml`을 만든다. `--output`으로 지정한 폴더가 이미 있으면 중단한다. 보고서에는 코드/검사/명세/합성 조건의 SHA256이 포함된다.

이번 결과 폴더: `verification/.work/independent-lateral-20261025-024213Z-44a693ea/`. 공유용 수치 요약은 [JSON 결과](lateral_foundation_2026-10-25.json)에 보존한다. 기존 검증 JSON과 manifest를 갱신하지 않았다.
