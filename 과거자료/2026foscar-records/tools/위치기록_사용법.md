# 자동 경로 주행 + 수집 위치 기록

명령 하나로 카메라 창·센서 수신·자동 주행·위치 기록이 함께 실행됩니다.
기존 정지선 표 없이 베이스라인 경로를 5 km/h로 따라갑니다.
신호·장애물 자동 대응은 없으므로 신호나 장애물 전에 여유 있게 정차하세요.
이 프로그램은 지점별 사진 한 쌍을 기록합니다. 연속 데이터셋 수집/학습은 하지 않습니다.

## 시작
1. 기존 위치 기록 프로그램은 q + Enter로 종료하고, 별도로 켜둔 카메라 창도 닫습니다.
   다른 진단·수집·주행 터미널도 Ctrl+C로 종료합니다.
2. MORAI에서 parking_scenario 로드, Keyboard + P로 놓습니다.
3. GPS 9102, IMU 9104, Competition Status 9099, RGB 9208, Semantic 9210의
   목적지를 개발 PC 192.168.0.10으로 연결합니다. RGB/Semantic 위치·각도·해상도·FOV를 맞춥니다.
4. MORAI Cmd Control은 기존 베이스라인 설정(수신 9093)을 연결합니다.
5. 개발 PC 터미널에서 실행합니다:

```bash
cd /home/foscar/Desktop/2026Morai/2026foscar
./tools/survey_points.sh
```

카메라 창이 자동으로 열립니다. 별도 카메라 런처는 실행하지 않습니다.
카메라 창은 영상 확인용입니다. 명령 입력 전 실행 터미널을 클릭하세요.
처음에는 브레이크를 유지합니다. Auto/D 전환은 프로그램이 요청합니다.
별도 빌드는 필요 없지만 기존 ROS 워크스페이스 빌드는 있어야 합니다.

## 조작 — 반드시 개발 PC의 실행 터미널에 입력
- `g` 입력 후 Enter: 자동 출발/재출발.
- Enter만 누르기: 브레이크 요청 후 실제 정지 1초를 확인하고 촬영 위치 저장.
- `l` 입력 후 Enter: 정차 후 정지선 기준점 저장.
- `q` 입력 후 Enter: 정차 및 종료, 카메라 창도 함께 닫힙니다. Ctrl+C도 종료합니다.
- 카메라 창의 X 또는 창에서 q를 누르면 전체 실행이 종료되고 브리지의 정차 절차가 실행됩니다.
- 저장 뒤에는 계속 정차합니다. 다시 g를 입력해야 움직입니다.
- MORAI의 Q/P로 개입하면 경로 추종기가 FAULT가 될 수 있습니다. 정상 정차는 위 Enter로 합니다.

## 결과
`~/foscar_logs/survey/날짜_시각/` 아래:
- `points.csv`: 종류, X/Y, s, 방향.
- `0001_capture/` 등: RGB/semantic 원본과 point.json.
- `launch.log`: 주행·센서 로그. 저장되지 않거나 주행이 안 되면 확인합니다.

좌표는 후륜축 기준입니다. `stopline_reference`도 사람이 정지선을 보고 세운 차량 위치이며,
실제 정지선의 좌표를 자동 측정한 것이 아닙니다. 선과 앞바퀴의 관계를 확인한 뒤 보정해야 합니다.
GPS 추측항법 중, 움직이는 중, 데이터가 오래됐거나 RGB/semantic 시각 차이가 5ms 초과하면 저장을 기다립니다.
실제 MORAI에서 정차 거리·재출발 검증은 필요합니다. 먼저 한 지점만 시험하세요.
Semantic은 연습용 데이터 생성 허용 여부를 확인한 환경에서만 사용하며 본선용 센서가 아닙니다.

## 확정 카메라 설정
7번 RGB와 8번 Semantic 모두 위치 (0.40, 0, 1.80)m, 각도 (0, 0, 0)도,
1280×720, FOV 70도, 10Hz. 7번 Ground Truth=None, 8번 Semantic.
Viz Bounding Box 2D/3D 및 Enable Capture Sensor는 OFF.

## 첫 시험 순서
1. 창에 LIVE 영상이 들어오는지 확인합니다.
2. 터미널에서 g + Enter로 출발합니다.
3. 신호등이 잘 보이는 곳에 도착하기 전에 Enter로 정차를 요청합니다.
4. '저장:' 메시지가 나올 때까지 기다립니다. 이후 g + Enter로 재출발합니다.
5. q + Enter로 마친 뒤 실제 차량 정지를 확인합니다.

## 안 될 때
- 영상에 NO RECENT CAMERA DATA: 카메라 7 Connect와 목적지 9208 확인.
- 출발 안 됨: 실행 폴더 launch.log에서 status: 0인지 확인하고 Competition Status 연결 확인.
  연결 복구 전 Enter로 출발 요청을 취소하세요.
- Auto/D handshake timeout: Cmd Control 수신 9093 연결 확인 후 프로그램을 종료·재실행.
- 저장 대기: RGB와 Semantic 둘 다 연결, 동일 Hz, GPS 위치 수신 여부를 확인합니다.
- 저장 폴더는 실행할 때 터미널에 출력됩니다. 기존 데이터는 덮어쓰지 않습니다.
