# 회전교차로 — 현재 개발 상태

최종 정리: 2026-09-25. 이 문서가 회전교차로 동작·검증 상태의 기준입니다.

## 실행과 미션 소유권

```bash
bash run_competition.sh rviz:=true
```

기본값은 `roundabout_control:=true`, `roundabout_local_entry:=true`입니다.
`src/ctrl_planning/config/missions.yaml`의 후륜축 global s `[860,920)`에서만 회전교차로 제어가 작동합니다.
미션 상한은20 km/h이며 곡선/전방 거리 제어가 더 낮은 목표를 낼 수 있습니다.
다음 미션에 넘어가면 진입 허가, 앞차 기억, 이전 상태의 대기를 초기화합니다.
보행자 검출에 의한 양보는 보행자 미션에서만 가능합니다.
고속도로 `[1119,1875)`는 CRUISE만 허용하며 공통 차량 YIELD도 개입하지 않습니다.

## 현재 객체만 사용하는 판단

- 정상 수신된 최신 `/perception/footprints` 전체 스캔에 있는 객체만 점유·충돌 예측에 사용합니다.
- 스캔에서 사라진 객체는 즉시 제거합니다. 다른 토픽의 캐시 메시지가 되살릴 수 없습니다.
- 같은 ID로 재등장해도 원호 및 앞뒤끝 속도 추정 이력은 새로 시작합니다.
- 연속으로 보이는 동안의 짧은 관측 연결은 원호 방향 속도와 경계 이동을 계산하는 데 사용합니다. ID는 내부 메시지 연결 수단입니다.
- 새 스캔 후 다음 제어 주기에 예측을 갱신합니다. 역순·중복 스캔과 잘못된 객체 목록은 무시합니다.
- 스캔 자체가0.45초 이상 끊기면 UNKNOWN입니다. 정상 스캔에서 객체가 없는 상황과 센서 장애를 구분합니다.
- 이 정책은 회전교차로에 한정합니다. 상자가 옆으로 넘어가 보이지 않아도 유지해야 하는 상자 회피 경로는 그대로입니다.

## 진입과 추종

맵 경로에서 얻은 회전교차로 원호를 기준으로 선행 군집의 뒤끝과 후행 군집의 앞끝 사이에 자차가 들어갈 수 있는지 평가합니다.
관측된 끝 또는 근거가 있는 옆면 끝 추정을 사용하며, 원호 이동 속도로 진입 중 충돌을 확인합니다.
후행차의 접근 속도는 짧은 연속 관측 구간(최대0.6초)의 회귀 속도와 실제 경계 이동 속도 중 빠른 값을 사용합니다.
일부 점군만 보이다 앞끝이 드러나는 동안 평균 속도가 낮게 나오는 경우를 막기 위한 것으로, 일정 속도에는 배율이나 추가 대기시간을 붙이지 않습니다.
객체가 사라지면 이 속도 이력도 삭제됩니다. 이 값은 진입 전 충돌 검사에 적용하며 진입 후 뒤차 추종 제동을 추가하지 않습니다.
미확인 조각을 양쪽으로 완전한 차량 길이만큼 확장하지 않습니다. 확립된 차량의 가려진 부분과 미래 불확실성은 별도로 반영합니다.

감속하며 접근하더라도 진입 조건이 충족되면 정지 없이 출발할 수 있습니다.
선행차가 없거나 차량이 전혀 없는 경우의 진입 경로도 있으며, 기존 진입 통로 가시성 확인 조건은 유지합니다.
후행차 검사는 진입 시퀀스까지 적용하고, 진입 후에는 전방 실제 경로상의 점군과 거리를 조절합니다.
새 관측에 앞차가 없으면 계속 진행합니다. 센서 수신 중단은 별도로 처리합니다.

일반 출발의 초당3.6 km/h 목표 속도 상승 제한은 제거됐습니다.
가속 명령 상승률은초당3.0, 일반 가속 상한0.4, 회전교차로 진입 상한0.6입니다.
이는 정규화된 페달 명령이며 실제 가속도 단위가 아닙니다. 제동과 속도 상한은 즉시 적용합니다.

## RViz와 기록

기본 화면은 현재 미션과 판단에 필요한 정보만 표시합니다.
진입 전에는 관측 경계·선택한 틈·후행차 충돌 검사를, 진입 후에는 전방 경로 점유와 거리 제어를 표시합니다.
점유 영역은 실제 판단에 사용하는 앞뒤 경계를 반영합니다. 자세한 과거/미래 예측 표시는 `visual_details:=true`로 확인합니다.

판단 기록은 `/behavior/mission`, `/behavior/prediction`, `/behavior/target`, `/control/telemetry`에 남습니다.
기본 bag은 `~/foscar_logs/bags`, 제어 CSV는 `~/foscar_logs/follow_*.csv`에 저장됩니다.

## 검증 범위와 남은 확인

- 최신 스캔 정책 이전의 전체 코스 주행에서 회전교차로 진입·탈출을 확인했습니다.
- `run_20260925_213913`의 후행차 충돌 주행에서 부분 점군 평균 속도는11.1 km/h, 이후 관측 속도는약20 km/h였습니다. 수정 후 같은 진입 후보는21.5 km/h 접근을 반영해 거부됩니다.
- 이 기록의 충돌 전 자차 이동 거리는 기존 곡선 감속 예측 범위 안에 있어 자차 가속 모델은 변경하지 않았습니다.
- `run_20260925_225950`의 정차 관측에서는 점군 모양 변화로 접근 속도가 순간29~31 km/h로 튀었습니다. 최근 최대 경계 속도를 반영하는 현재 방식은 이 잡음을 키울 수 있으며, 경계 위치 변화와 실제 이동 속도를 구분하는 개선은 아직 미구현입니다.
- `drive:=false`에서도 진입 판단은 실행됩니다. GO 이후0.6초가 지나도 자차 속도가0.1 m/s 미만이면 미출발로 허가를 해제하고 다시 평가하므로, 움직이지 않은 채 GO/NO가 반복될 수 있습니다.
- 재생은 원본 자차 궤적을 사용합니다. 실제로 일찍 출발했을 때의 충돌 여부와 성공을 입증하지 않습니다.
- 후행차 속도 수정 후 실주행, 약10 km/h 접근, 정차 대기, 임의 차종·간격 조건에서의 재검증이 남아 있습니다. 한 스캔에서 잠깐 가려진 객체도 제거되는 정책의 실제 영향도 확인해야 합니다.
- 신선한 스캔에 객체가 없다고 해서 시야 밖까지 비어 있다고 보장하지 않습니다. 빈 도로 진입에는 통로 관측 조건이 남아 있습니다.

## 주요 코드

- `ctrl_circular_gap.py`: 최신 스캔 객체 집합, 원호 점유·진입 검사
- `ctrl_boundary_motion.py`, `ctrl_observed_boundary.py`: 앞뒤끝 속도와 관측 근거
- `ctrl_entry_gate.py`: 접근·진입·추종 상태
- `ctrl_local_following.py`, `ctrl_measured_corridor.py`: 진입 후 전방 거리 제어
- `ctrl_prediction_markers.py`, `ctrl_mission_markers.py`: RViz 진단
- `ctrl_mission.py`, `config/missions.yaml`: 체크포인트별 소유권

위 파일은 `src/ctrl_planning/ctrl_planning` 기준이며 설정 파일은 패키지 루트 기준입니다.
