# 이름 하나로 수집하고 자동 라벨링하기

> **2026-09-27 인수인계:** 기존 정지선 표는 재측정 대상입니다. 현재 카메라 설정·실행 순서는 [새 PC 인수인계](../../YOLO_다른PC_인수인계.md)를 보세요. 아래 과거 기록과 구분합니다.

MORAI에서 날씨·시간을 설정한 뒤, 레포에서 실행한다.

```bash
cd /home/foscar/Desktop/2026Morai/2026foscar
./tools/collect_label.sh foggy_13h
```

이름 없이 `./tools/collect_label.sh`만 실행하면 조건 이름을 입력받는다.
영문·숫자로 시작하고 영문·숫자·밑줄·하이픈만 사용한다 (최대 80자).
같은 조건은 같은 이름을 사용해도 된다. 실행마다 날짜·시각이 붙는다.

1. ROS 환경을 자동으로 불러오고 `ctrl_record.launch.py`를 실행한다.
2. 기본 20 km/h로 이동하고, 경로에 등록된 정지선마다 실제 정지 확인 후 **60초 대기**한다.
   대기 중에도 2초 간격으로 저장하며, 시간이 끝나면 다음 정지선으로 이동한다. 로그에서 GPS·IMU·STATUS의 RX와 recorder의 `s`가
   들어오는지 확인한다. `s -`가 계속 나오면 위치 정보가 없는 상태다.
3. 원하는 구간을 지나면 **Ctrl+C를 한 번** 누른다.
4. ROS 종료 및 저장 완료를 기다린 뒤 **이번 실행에서 생긴 세션만** 자동 라벨링한다.
5. 완료 메시지에 원본·결과·검수 폴더 경로가 나온다. 프로그램은 한 번 처리한 뒤 끝난다.

다음 조건은 MORAI에서 직접 바꾸고 이름을 바꿔 다시 실행한다.

```bash
./tools/collect_label.sh sunny_11h
./tools/collect_label.sh foggy_15h
```

`tag`는 기록용 이름이다. 프로그램이 MORAI의 날씨·시간·카메라 설정을 바꾸지 않는다.
시나리오 Load 뒤에는 네트워크 연결이 풀릴 수 있으므로 다시 확인한다.

## 출력

```text
~/foscar_logs/dataset/날짜_시각_조건/     원본 RGB·semantic 및 meta.csv
out/날짜_시각_조건/                    실행마다 새로 생성되는 결과 폴더
├── dataset/                          YOLO 라벨 초안·이미지·data.yaml·roi.json
├── review/                           의심되는 자동 판정을 그린 검수 이미지
├── frames.json                       Roboflow 내보내기용 프레임 정보
└── summary.json                      완료/미완료 상태·원본 경로·라벨 및 분할 통계
```

위치 `s`가 누락됐거나 유한하지 않은 사진은 라벨 출력에서 제외한다. 원본은 삭제하지 않는다.
위치가 있는 사진이 하나도 없으면 오류로 끝나며 빈 데이터셋을 성공으로 보고하지 않는다.
라벨링 중 Ctrl+C를 누르면 라벨링을 중단한다. 이 경우 결과는 `summary.json`에
`incomplete`로 표시되므로 학습에 사용하지 않는다. 수집 중 SIGTERM으로 종료해도
저장 종료를 기다리지만 자동 라벨링으로 넘어가지 않는다.
수집 노드가 중간에 비정상 종료하면 자동 라벨링을 시작하지 않고 원인을 출력한다.

자동 라벨은 초안이다. `review/`와 일반 사진의 박스·클래스도 확인해야 한다.
현재 카메라 각도·ROI·팔레트·종횡비 임계값은 유지된다. 자동으로 학습하거나 업로드하지 않는다.
val에 라벨이 있는 사진이 없으면 경고한다. 여러 조건을 모은 뒤 정상 세션들만 지정해서
조건·정지선 단위로 재분할해야 한다.

## 선택 옵션

```bash
./tools/collect_label.sh foggy_13h --stop-seconds 90  # 정차 시간을 90초로
./tools/collect_label.sh foggy_13h --stop-seconds 0   # 정차 기능 끄기
./tools/collect_label.sh foggy_13h --speed-kmh 10
./tools/collect_label.sh foggy_13h --no-drive   # 제어 명령 없이 수동 주행으로 수집
./tools/collect_label.sh foggy_13h --data-root ~/foscar_logs/dataset --out-root out
./tools/collect_label.sh --help
```

정차 노드가 추가됐으므로 처음 한 번 빌드한다 (현재 머신에서는 완료).

```bash
source /opt/ros/humble/setup.bash
colcon build --packages-select ctrl_camera_train --symlink-install
source install/setup.bash
```

직접 런치할 때도 기본 60초 정차가 적용된다.

```bash
ros2 launch ctrl_camera_train ctrl_record.launch.py tag:=foggy_13h stop_seconds:=60
```

`--no-drive`, `drive:=false`, `check:=true`에서는 정차 제어를 실행하지 않는다.
정차 위치는 `ctrl_camera`의 정지선 표를 공유하고 앞바퀴 기준으로 맞춘다.
`config/record.yaml`의 `collection_stop_node.stop_before_m`을 늘리면 그만큼 앞에서 멈춘다.
실제 카메라 화면을 보고 조정하며, 기본값은 기존 정지선과 같은 0 m다.

60초는 고정 대기 시간이며 신호 사이클 완료를 감지하는 기능은 아니다.
MORAI의 사이클이 더 길면 `--stop-seconds`를 늘린다. 대기 후에는 신호색과 무관하게 출발한다.
각 정지선은 한 실행에서 한 번 대기한다. 위치·속도 수신이 끊기거나 차량이 움직이면
대기 시간을 다시 센다. 정지선을 지나쳐 `COLLECT_MISSED_STOP`이 뜨면 정지 상태를 유지하므로
수집을 종료하고 차량 위치를 조정한 뒤 새로 실행한다.
정차 제어가 활성화된 수집 런치에서만 `require_target=true`를 적용한다.
MORAI 실제 제동 위치와 정차 중 신호등 가시성은 아직 검증하지 않았다.

자동 라벨링만 다시 실행하려면 원본 세션을 명시한다. 출력에는 새 폴더 이름을 사용한다.

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
python3 -m ctrl_camera_train.ctrl_extract \
  --session ~/foscar_logs/dataset/날짜_시각_조건 \
  --out out/relabel_조건 --require-s
```


## 다음 실행에서 확인할 것

1. MORAI 목적지 IP `192.168.0.10`에 GPS `9102`, IMU `9104`,
   **Competition Vehicle Status** `9099`를 연결한다.
   GPS·IMU RX가 증가하는데 STATUS만 0이면 GPS·IMU 연결 실패가 아니다.
   일반 Vehicle Status의 229 B 패킷은 Competition 형식 181 B와 호환되지 않는다.
2. 날씨·시간·시작 위치를 설정하고 조건 이름을 지정해 실행한다.
3. 첫 정지선에서 `COLLECT_HOLD`, 남은 시간 감소, 60초 후 재출발을 확인한다.
   카메라 각도는 유지하고, 정차 중 신호등이 화면에서 잘리지 않는지 확인한다.
   필요하면 실측 후 `stop_before_m`을 조정한다.
4. 원하는 구간을 마치면 Ctrl+C 한 번으로 종료하고 자동 라벨·검수 이미지를 확인한다.
5. 다른 조건은 MORAI를 직접 조작해 반복한다. 정상 세션들만 명시해 합치고
   조건·정지선 단위로 분할한다. 무작위 프레임 분할은 하지 않는다.
6. Roboflow는 먼저 50장으로 왕복 검증한다. Auto-Orient/Resize/Augmentation을 끄고,
   학습 시 `fliplr=0.0`, `hsv_h=0.0`을 유지한다.

기본 클래스는 `red`, `yellow`, `green`, `green_left`, `left`, `pedestrian`이다.
Roboflow가 번호를 재배열할 수 있으므로 실제 학습·평가에는 해당 데이터셋의
`data.yaml`에 있는 `names`를 사용한다.

현재 패키지 빌드와 테스트 135개는 통과했다. 실제 MORAI 정차 주행과 전체 신호 사이클 관측,
Roboflow 왕복·Colab 학습은 아직 완료 확인 전이다. 데이터별 상태는 [개발구조.md](개발구조.md)에 기록했다.
